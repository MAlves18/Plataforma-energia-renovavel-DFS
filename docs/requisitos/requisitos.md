# Requisitos

## Funcionais
- RF01 Cadastro de municípios/comunidades e dados socioeconômicos.
- RF02 Cadastro de indicadores/critérios.
- RF03 Configuração dos pesos TOPSIS.
- RF04 Execução do TOPSIS e geração de ranking.
- RF05 Dashboard.
- RF06 Geração de relatório CSV.
- RF07 Preparação de visualização georreferenciada.
- RF08 Usuários e perfis.
- RF09 Estrutura para importação de dados externos.
- RF10 Histórico de simulações.

## Não funcionais
- RNF01 desempenho do cálculo para 500 alternativas.
- RNF02 interface responsiva.
- RNF03 disponibilidade alvo de 99,5%.
- RNF04 JWT e bcrypt.
- RNF05 cobertura de testes alvo de 80%.
- RNF06 documentação Swagger/OpenAPI.
