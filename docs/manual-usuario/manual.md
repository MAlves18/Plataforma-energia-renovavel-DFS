# Manual do usuário

1. Inicie o sistema com `docker compose up --build`.
2. Acesse o frontend em `http://localhost:5173`.
3. Consulte o Dashboard.
4. Entre em **Simulação TOPSIS**.
5. Ajuste os pesos dos critérios.
6. Clique em **Executar TOPSIS**.
7. Consulte o ranking.
8. Use **Municípios**, **Critérios**, **Mapa** e **Histórico** para consultar as demais áreas.
9. Para obter o CSV da última simulação, acesse `/api/relatorios/latest.csv`.
10. A documentação da API fica em `/docs`.

## Observação
Os dados demonstrativos servem para validação acadêmica do fluxo e podem ser substituídos por dados oficiais importados.
